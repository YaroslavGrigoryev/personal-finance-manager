# Personal Finance Manager


## Функциональность

- Регистрация и авторизация пользователей
- Отдельный кошелёк каждого пользователя
- Добавление доходов и расходов
- История операций и финансовая статистика
- Лимиты расходов по категориям
- Проверка превышения бюджета
- Просмотр всех бюджетов
- Расчёт расходов по выбранным категориям
- Предупреждение об отсутствующих категориях
- Сохранение и восстановление данных из файла

## Требования

- Java 21
- Maven

## Сборка и тестирование

```bash
mvn clean package
```

## Запуск

```bash
java -cp target/classes com.mycompany.finance.FinanceApp
```

Данные сохраняются в `users.dat` при штатном выходе через
команду `0` и загружаются при следующем запуске.

## Ограничения

Проект учебный. Пароли пока хранятся без хеширования,
а Java-сериализация предназначена только для локальных
доверенных файлов. Не публикуйте `users.dat`.
